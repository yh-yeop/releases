# Releases

**YTDL** · **MP3Checker** 설치 파일 배포 전용 저장소입니다. (소스 코드는 비공개)

## 다운로드

[Releases 페이지](https://github.com/yh-yeop/releases/releases)에서 최신 설치 파일을 받을 수 있습니다.

| 앱 | 태그 형식 | 설치 파일 |
|---|---|---|
| YTDL — 유튜브 → 커버·싱크가사 포함 MP3 | `YTDL-v<버전>` | `YTDL-Setup-<버전>.exe` |
| MP3 Checker — MP3 라이브러리 점검 도구 | `MP3Checker-v<버전>` | `MP3Checker-Setup-<버전>.exe` |

설치된 앱은 시작 시 이 저장소를 확인해 새 버전이 있으면 자동으로 안내합니다.

## 권리자·서비스 제공자 요청

이 앱들과 관련해 저작권 침해 신고(DMCA 등)나 서비스 접근 중단 요청이 있으면
**확인 즉시 따릅니다** — 해당 기능 제거·배포 중단 포함. 요청은 이 저장소의
[Issues](https://github.com/yh-yeop/releases/issues)로 남겨 주세요.

## 배포 규칙 (관리용 메모)

- 태그는 반드시 `YTDL-v1.2.0` / `MP3Checker-v1.3.0` 형식 (앱들이 접두사로 자기 릴리스를 구분)
- 에셋 파일명에 `Setup` 이 포함된 `.exe` 를 첨부해야 앱이 인식
- 드래프트·프리릴리스는 업데이트 안내에서 무시됨
